# Software

## CW Software

Software store for RPM-based atomic operating systems, providing a unified interface to manage system packages, sandboxed applications from Flathub, and system updates.

**Supported Platforms:** AlmaLinux Bootc, Fedora Atomic Desktops, and RHEL for Edge.
### Key Features

- **Atomic-First Design:** Built specifically for atomic operating systems, with their unique package management workflows in mind.
- **Fast and Reliable:** Designed to provide a smooth and dependable software management experience.
- **Filling the Gap:** Addresses the lack of a dedicated, unified software store tailored to RPM-based atomic systems.

### Contributing

Contributions are welcome. The project's scope is strictly limited to atomic operating systems; features and changes outside this scope will not be considered.
CW Software is written in Python, with a focus on a native GNOME look and feel.
AI-assisted contributions are welcome, provided that both the contributor and the reviewer manually review the changes before they are accepted.
